# Surakarta room protocol (network v1)

Transport: JSON text over WebSocket; websockets==15.0.1 (Python 3.10+).
Both LAN and online run exactly the same authoritative room service. No Pygame imports in networking/server.py or server/.

Client sends: {type:create, version:1, name:str}; {type:join,version:1,room:str,name:str}; {type:resume,version:1,room:str,token:str}.
After binding: {type:ready}; {type:move,revision:int,start:[row,col],end:[row,col]}; {type:resign}; {type:leave}; {type:sync}.
Server sends: {type:welcome,version:1,room:str,color:'black'|'red',token:str}; then snapshots.
Snapshot: {type:state,version:1,room:str,revision:int,status:'waiting'|'playing'|'finished',board:[6 strings of B/R/.],turn:'black'|'red',ply:int,players:{black:{name:str,connected:bool,ready:bool},red:null|same},moves:[{start:[r,c],end:[r,c],color:'black'|'red',capture:bool,text:'B2A-3A'}],result:null|{winner:'black'|'red'|null,reason:str},reconnect_seconds:int}.
Errors: {type:error,code:str,message:str}, followed by current state for stale move. Do not echo tokens or raw exceptions. Client also emits local {type:connection,status:'connected'|'disconnected'|'error',message:str} events.

Rooms: creator black, joiner red. Both must ready before board can move. Validate side, coordinates, exact current revision, and membership in board.legal_moves(); never trust capture flag. Move submit doesn't change local board until authoritative snapshot. Require both players connected for moves. Use server serialization (async event loop with per-room lock or broadcast queue) to keep event revisions ordered. Reject join to occupied room; resume token reclaims disconnected seat. Reconnect grace default 60s, no move-clock first version. Resign/leave ends live game; disconnect pauses, grace expiration awards connected opponent or closes abandoned game. Room limits, frame limits, bounded idle retention and request rate limits required.
Room end rules: zero pieces, side with no legal move loses, 3-fold full position including turn draws, 80 plies without capture draws. Explicit room rules (not a claim of official tournament rules).

Server API (networking/server.py): EmbeddedServer(host='0.0.0.0',port=8765,**options).start() -> self (wait startup, port property resolves port=0), .stop(); .port, .host. The standalone CLI uses the async RoomService directly. Server startup errors propagate to the caller.
Client API (networking/client.py): NetworkClient(url,name='玩家').start(mode='create'|'join',room='') (nonblocking), .poll() -> list[dict] (drain events), .send(type, **fields) (nonblocking), .reconnect() (uses in-memory token), .close() (nonblocking close, token cleared only object disposal); attributes .room, .color, .token, .connected. Worker owns network IO; don't touch Pygame from worker. Manual reconnect button, no silent user move replay. Validate ws/wss URLs; proxy=None for direct LAN; bounded queues and clear failures.

UI panel API (Class/Element/NetworkPanel.py): NetworkPanel().open(active=False, room='', color='', status='', address='') sets .visible=True. .draw(screen), .handle_event(event)->None|dict; .message string for status; .set_session(room='',color='',status='',address='',active=True). Mode tabs: '局域网建房' (host), '局域网加入' (join_lan), '在线房间' (online). Inputs nickname, server address, room code (no account). Actions dicts: {action:'host',name:str,port:int}; {action:'connect',name:str,url:str,mode:'create'|'join',room:str}; {action:'ready'|'reconnect'|'resign'|'leave'|'close'}. Validate inputs and show Chinese errors without raising. Address copied/pasted via keyboard support; address field for online ws:// or wss://, LAN host/IP:port -> ws URL. Show room code/seat/connect state plus nickname and setup instructions. In-session buttons ready/reconnect/resign/leave, close overlay via Escape without leaving. No business/connection logic in panel.
